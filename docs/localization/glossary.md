# Glossar – redaktioneller Begleiter

Die JSON-Datei ist maschinenlesbares SSOT. Dieses Dokument erklärt die Schreibabsicht.

| Begriff | Deutsch | Englisch | Regel |
|---|---|---|---|
| Rift | Rift | Rift | Eigenbegriff; keine Portalumschreibung |
| Riftanker | Riftanker | Rift Anchor | feste Zusammenschreibung DE |
| Riftwarden | Riftwarden | Riftwarden | Titel nicht lokalisieren |
| Echo | Echo | Echo | magischer Weltbegriff |
| Pip | Pip | Pip | Name unverändert |
| Kurator | Kurator | Curator | Rollenbegriff |

Neue Begriffe werden zuerst in JSON mit Preferred-/Forbidden-Varianten und Kontext ergänzt. Die eigentliche Copy darf nicht vor dem Glossareintrag `approved` werden.
