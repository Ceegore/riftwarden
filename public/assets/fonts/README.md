# Font input gate

Keine Fontdatei ist in diesem Planungspaket enthalten. Vor der echten Umsetzung müssen genehmigte lokale WOFF2-Dateien für Noto Sans UI und Cinzel Display sowie die zugehörigen OFL-Lizenztexte in exakt den im Manifest eingetragenen Pfaden bereitgestellt werden. Hash, Quelle, Version, Subsetting, Glyphprobe und Lizenz müssen im Font-Evidencebericht stehen. Remote-Fonts und Runtime-Netzwerk sind verboten.
